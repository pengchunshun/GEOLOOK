星火之光 SparklightAIGEOLOOK

产品设计说明书 · 基于 GEOLOOK 的开源架构定制开发 · 2026-08-22

本说明书面向产品、研发与交付团队，基于开源项目 GEOLOOK 的真实架构能力，定义「星火之光 SparklightAIGEOLOOK」的定制开发方案。GEOLOOK 是端到端星火之光生成式引擎优化（GEO）自托管平台：状态分析 → 诊断 → 策略 → 执行工单 → 实施 → 验收。星火之光在其之上，强化 AI 原生能力、品牌化交付与多租户协作，形成一套可对外商业化的 GEO 服务平台。

1. 产品定位

GEOLOOK 解决了「AI 从不提你、不知为何不提、建议落不了地、做了没验证、交付打包难」五大问题，其核心价值是「GEO 的终点不是排名，是 AI 答案里那句话是不是按你的口径说的」——最小单位是可被抽取的事实块而非页面。

星火之光的定位升级为：面向品牌方与 GEO 服务商的 AI 原生 GEO 增长平台。在保留 GEOLOOK「监测→诊断→工单→资产→自动验收→交付」完整闭环与数据本地化、零编造纪律的基础上，叠加四层定制能力：① 多模型 AI 智能体（自动扩词/初稿/事实核验）；② 品牌化白皮书级交付物与多租户客户空间；③ 实时仪表盘与协作工作流；④ 国内/海外双市场策略模板与行业知识库。

2. 目标用户与场景

  • ● 品牌增长团队：自有官网/小程序，需持续提升在 ChatGPT、豆包、DeepSeek 等 17 个引擎中的提及与引用。
  • ● GEO/SEO 服务商：同时服务多个客户，需要多租户空间、批量复跑与可白标交付包。
  • ● 内容/公关团队：基于「可抽取事实块」方法论，规模化产出被 AI 引用友好的内容资产。
  • ● 出海企业：国内 + 海外双市场的并行 GEO 战场，需要分市场指标与渠道地图。

    3. 功能架构（基于 GEOLOOK 管线扩展）

    沿用 GEOLOOK 的九步管线（建项目→抓取→体检→推导底座→采样→工单→资产→报告→验收→交付），在每一层叠加星火之光的定制模块，形成六层架构：

  • ● L1 接入层：3 步品牌接入向导（URL + 市场）、无站点模式（电商/线下品牌）、多租户空间切换。
  • ● L2 数据底座层：复用 crawl/audit/bootstrap；新增行业知识库与品牌事实库多版本管理。
  • ● L3 智能采样层：复用 17 引擎采样 + 样本库人工校正；新增多智能体采样编排（自动选题/复核/降噪）。
  • ● L4 诊断策略层：复用四层依赖链体检、差距诊断、19 渠道地图；新增AI 诊疗建议生成与竞品情报雷达。
  • ● L5 执行交付层：复用工单/资产/发布/验收；新增协作工单流、品牌化白皮书、月报订阅。
  • ● L6 展示层：复用单文件暗色四段主线 UI；升级为星火之光品牌视觉系统 + 实时仪表盘 + 客户只读视图。

    4. 核心业务流程

    主流程在 GEOLOOK 的九步管线上扩展出「AI 智能体编排」与「品牌化交付」两个新环节：

  • ● 接入：3 步向导 → 自动推断品牌名/市场 → 创建多租户客户空间。
  • ● 底座构建：抓取 + 六维体检 + 自动推导品牌事实/竞品/问题库（复用 bootstrap，新增行业知识库增强）。
  • ● 智能采样：多智能体自动选题 → 17 引擎采样（API + 浏览器插件）→ 样本库人工校正 → 自动降噪。
  • ● AI 诊疗（新增）：基于 method.md 实测口径，由诊疗智能体生成诊断结论、修复顺序与策略建议。
  • ● 执行：协作工单流（指派/评论/风险分级）→ 内容工作台（AI 初稿 + 编造风险 lint）→ 资产部署 → 发布。
  • ● 验收交付：自动验收（回归重开）→ 品牌化白皮书 + 月报订阅（新增）→ 客户只读视图。

    5. 功能详细说明（新增与优化模块）

    5.1 多智能体 AI 引擎（新增·核心）

    在 GEOLOOK 仅用单一 LLM 出初稿的基础上，构建可编排的智能体集群，统一接入已配置的引擎 Key：

  • ● 扩词智能体：基于百度下拉/Google 补全 + 行业知识库，自动产出高意图候选题并标注意图分组。
  • ● 初稿智能体：基于 content-patterns 模板生成可引用内容大纲与初稿，强制过编造风险 lint。
  • ● 事实核验智能体：对照品牌事实库（A–E 证据等级）自动标记初稿中无来源/存疑数字，阻断编造。
  • ● 诊疗智能体：将体检四层链 + 样本库指标，生成可读诊断结论与修复优先级（追到 method.md 数字出处）。

    • 5.2 行业知识库（新增）

  • ● 按行业（SaaS/电商/医疗/教育…）预置信源权重、问题模板、竞品维度，使新项目 bootstrap 更准更快。

    • 5.3 多租户客户空间（新增）

  • ● 团队账号 + 角色（管理员/运营/编辑/只读客户）；每客户独立 work// 空间，互不越权。
  • ● 客户只读视图：可分享链接（带 token）查看仪表盘与月报，无编辑权限——对应 GEOLOOK 的公网 token 机制。

    • 5.4 协作工单流（优化）

  • ● 工单由本地 tasks.json 升级为带指派/评论/状态流/风险分级的协作对象；回归自动重开保留。

    • 5.5 品牌化白皮书与月报（优化·交付）

  • ● 三份基础交付物升级为统一的星火之光白皮书视觉（封面/品牌色/结论先行/可引用证据链）。
  • ● 月报订阅：定时生成并分发（邮件 + 客户只读链接），含 delta、信源 Top、大盘对照。

    • 5.6 实时仪表盘与竞品雷达（优化·展示）

  • ● 现状总览升级为实时卡片（健康分/提及率/引用份额/阵地/任务/内容），新增竞品情报雷达图。

    • 5.7 品牌视觉系统（新增·全链路）

  • ● 统一「星火之光」暗色科技风视觉：深空蓝紫底 + 星火橙金强调色 + 火花/光晕图标语言，覆盖 UI、白皮书、月报。
