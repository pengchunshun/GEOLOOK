1 GeoBench NomaDamas/geobench

对标 Profound/Semrush/AthenaHQ 的开源 GEO Benchmark。覆盖 OpenAI、Anthropic、Google、Perplexity、xAI、OpenRouter 等 6 家供应商，计算命中率、语义排名 MRR、竞品声量份额 SoV、引用率、情感分析，带 Bootstrap 95% 置信区间与本地只读仪表盘（Vite，:5173）。支持跨"API/CLI/浏览器"三角验证、断点续跑。

2 GEOVisibilityTool MasashiToda1/GEOVisibilityTool（原 KnightMafiaLau）

模块化 GEO 测试 harness，由 6 个 Claude Code Skill 组成（生成测试问题 → 浏览器操作真实 LLM 网页端提问 → 算 0–100 可见度分 → 出 CEO 报告 → 给投放渠道建议）。支持国内 Kimi/豆包/DeepSeek/文心/千问/元宝；probe.py 仅用 Python 标准库、零外部依赖；全本地运行，数据存 ~/.geo-kb/kb.sqlite。Apache-2.0。

资源获取明细

资源类型可能来源获取路径描述
源码仓库GitHubgit clone https://github.com/KnightMafiaLau/GEOVisibilityTool.git
客户端Anthropic安装 Claude Code（或任意支持 Anthropic Skills 的 Claude 客户端）
技能安装本地目录将 skills/ 下 6 个模块 cp 到 ~/.claude/skills/，重启客户端
浏览器自动化MCP配置浏览器 MCP server 供 probe.py 操作 LLM 网页端
数据集运行时生成测试问题由 geo-queries 基于品牌信息动态生成；无外部公开数据集
知识库本地 SQLite每次运行累积到 ~/.geo-kb/kb.sqlite，备份即 cp；示例见 examples/（如简知 App 案例）
Hooks 约束仓库 hooks/hooks/install.sh（需 jq，自动备份 ~/.claude/settings.json）
社区渠道GitHubIssues（Recipe Broken / Query Feedback / Channel Pattern 模板）、Discussions、CONTRIBUTING.md、TASKS.md 路线图

3 OneGlanse aryamantodkar/oneglanse

自称"唯一免费开源 GEO 追踪器"。通过抗指纹浏览器（Camoufox/Playwright）对抗真实产品 UI（非 API）捕获 ChatGPT/Gemini/Perplexity/Claude/Google AI Overview 的实际回复、内联引用、竞品共现；自带 LLM Key 做 GEO 打分；ClickHouse 时序存储；单命令 Docker 部署。MIT，153★。

运行环境Node/DockerNode.js 20+ / pnpm 10+ / Docker；cp .env.example .env → pnpm local 启动 :3000
关键依赖库开源生态Camoufox（MPL-2.0 抗指纹 Firefox）、Playwright、BullMQ、ClickHouse、Drizzle ORM、Better Auth、Turndown

5 GEO-AEO Tracker Bright Data · danishashko/geo-aeo-tracker

Bright Data 官方开源的本地优先 AI 可见性仪表盘。Prompt Hub 并行跑 6 个模型（ChatGPT/Perplexity/Gemini/Grok/Google AI Mode/Copilot），生成 0–100 可见度评分、引用机会（竞品被引而你未出现的 URL）、SRO 优化分析、Drift 告警、竞品 Battlecards。数据存浏览器 IndexedDB，无外部数据库。

结论建议

  • 与 GEOLOOK 最可比的是 GeoBench（指标方法论最严谨）与 OneGlanse（真实 UI 捕获、社区最活跃）。
