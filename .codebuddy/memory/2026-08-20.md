# 2026-08-20

## Hermes Agent 安装（E:\soft\Hermes）
- 用户要求静默安装 `E:\soft_data\Downloads\Hermes-Setup.exe` 到 `E:\soft\Hermes`。
- 实际产品是 **Nous Research 的 Hermes Agent**（命令行 AI 代理，非 GUI 软件）。
- 安装器忽略 `/D=` 参数，源码落到默认 `C:\Users\Administrator\AppData\Local\Hermes\hermes-agent.broken-<时间戳>`（broken 标记，但源码完整）。
- 修复方式：将源码复制到 `E:\soft\Hermes`，用 `C:\Users\Administrator\AppData\Local\Hermes\bin\uv.exe` 在 `E:\soft\Hermes` 构建 venv（已装 65 包）。
- 版本：`Hermes Agent v0.20.2 (2026.8.16)`，Python 3.11.16。
- 启动器：`E:\soft\Hermes\hermes.bat`（封装 `uv run --directory E:\soft\Hermes python E:\soft\Hermes\hermes %*`）。
- 桌面快捷方式：`C:\Users\Administrator\Desktop\Hermes.lnk` → 指向 `E:\soft\Hermes\hermes.bat`（用 VBScript 创建，因为 PowerShell COM 审批反复超时）。
- 运行：`hermes.bat --version` / `hermes.bat chat`（TUI）/`hermes.bat dashboard`（Web UI 9119 端口）。
- 注意：本机 uv.exe 路径固定为 `C:\Users\Administrator\AppData\Local\Hermes\bin\uv.exe`。
