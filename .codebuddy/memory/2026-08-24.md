## 任务：安装 OpenClaw 到 E:\soft\OpenClaw 并生成桌面快捷方式

### 关键发现（重要）
- 官网 https://openclaw.ai/ 提供的 Windows 安装包链接
  `https://github.com/openclaw/openclaw/releases/latest/download/OpenClawCompanion-Setup-x64.exe`
  **实际 404**（GitHub 该 release 只有 2 个 asset，无 Windows exe 安装包）。
  OpenClaw 目前**没有预编译 Windows 安装程序**，Windows 只能靠 `install.ps1` 脚本安装
  （npm 全局 / git 克隆两种方式）。
- 本机环境：git 2.54、Node v22.23.2、npm 12、corepack 0.34.6、Windows 10/11 x64。
- GitHub 大流量连接不稳定（git clone / GitHub API 报 connection reset / 403），但
  `https://github.com/openclaw/openclaw/archive/refs/tags/v2026.7.1-2.zip` 的 tarball
  下载稳定（75MB，已成功）。

### 安装方式（最终采用）
- 从 GitHub 下载 tag `v2026.7.1-2` 的 tarball，解压到 `E:\soft\OpenClaw`（60 个顶层文件，完整 monorepo 源码）。
- 用 corepack 启用 pnpm@11.2.2，`pnpm install`（162 工作区，约 7.5 分钟，INSTALL_EXIT=0）。
- `pnpm build` 生成 `dist/entry.js`（约 13 分钟，BUILD_EXIT=0）。
- `openclaw.mjs` 是 launcher：必须 `dist/entry.js` 存在；无 dist 时报 "unbuilt source tree"。
  它不会自动用 tsx 跑源码，必须构建。

### 启动入口
- 主程序：`E:\soft\OpenClaw\openclaw.mjs`（需 node，版本要求 >=22.22.3）。
- 包装脚本：`E:\soft\OpenClaw\openclaw.cmd`（cd 到安装目录后 `node openclaw.mjs %*`）。
- 验证：`node E:\soft\OpenClaw\openclaw.mjs --version` → `OpenClaw 2026.7.1` (EXIT=0)。

### 桌面快捷方式（V2 - 修复版）
- 路径：`C:\Users\Administrator\Desktop\OpenClaw.lnk`
- 指向：`E:\soft\OpenClaw\openclaw.cmd` → 内部调 `powershell -File launch.ps1`
- 图标已修正为有效 Windows 图标：`E:\soft\OpenClaw\ui\public\favicon.ico,0`
- WindowStyle=7（最小化，不弹黑窗）。

### 启动入口（最终可用方案 - 重要）
- **OpenClaw 是本地 Web 应用，靠 `gateway` 子命令暴露 Web UI**，不是双击即见窗口的程序。
- 默认 `openclaw` 命令（无子命令）会进入无窗口/REPL 模式 → 这正是“桌面快捷方式打不开”的根因。
- 正确启动：`node openclaw.mjs gateway [--allow-unconfigured --auth none]`
- **Web UI 端口固定 `http://127.0.0.1:18789/`**（HTTP 200，含 `<title>`）。
- 必须先配置 `gateway.mode=local` + `gateway.bind=loopback`（用 `openclaw config set`），
  否则 gateway 会卡在要求配置 / 静默挂起不 bind 端口。
- `E:\soft\OpenClaw\launch.ps1`：检测 18789 是否已起，未起则后台 `node openclaw.mjs gateway
  --allow-unconfigured --auth none`（CreateNoWindow），轮询最多 40s 等端口就绪，最后
  `Start-Process http://127.0.0.1:18789/` 打开浏览器。
- `E:\soft\OpenClaw\openclaw.cmd`：仅 `cd` 后调 `launch.ps1`。
- 验证：双击 .lnk → 18789 UP + Edge 浏览器打开 UI（HTTP 200）。端到端通过。
